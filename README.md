# ❤️ CardioAI - Heart Disease Prediction System

CardioAI is a machine learning-based web application that predicts the likelihood of heart disease using patient health and clinical information.

The project combines **Data Analysis, Exploratory Data Analysis, Machine Learning, FastAPI, and a responsive web interface** into one complete system.

> **Note:** This project is developed for educational and research purposes. It is not a medical diagnostic tool and should not replace professional medical advice.

---

## 📌 Project Overview

Heart disease is one of the major health concerns worldwide. Early analysis of important health indicators can help identify potential risk patterns.

CardioAI uses a **Logistic Regression** machine learning model to analyze 13 patient health parameters and generate a heart disease prediction.

The system provides:

- Dataset analysis
- Exploratory data analysis
- Data preprocessing
- Machine learning model training
- Model evaluation
- REST API using FastAPI
- Interactive web interface
- Real-time prediction
- Model probability

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze a heart disease dataset
- Identify important patterns in patient health data
- Clean and preprocess the dataset
- Train a machine learning classification model
- Evaluate the performance of the model
- Develop an API for real-time predictions
- Build a user-friendly web interface
- Connect the frontend with the trained ML model
